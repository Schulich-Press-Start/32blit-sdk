# Start here: make your first scene

In the Windows **Scene Workshop** ZIP, open `START HERE.html`. Launch `Editor/32blit-editor.exe` and choose **File → New Project…**. Name the project `My Game` and use it for the rest of the workshop.

Follow [authoring](scene-workshop/Authoring.md) to import an animated coin, place two instances over a layered tilemap and use **Play Scene**. This part needs no compiler. Continue to [building](scene-workshop/Building.md) to run the same scene outside the editor, then [program Pong](scene-workshop/Gameplay.md) in small C++ steps.
