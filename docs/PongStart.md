# Start here — make Pong in 32blit

1. Extract the entire Windows x64 ZIP to a writable folder. Open **`Editor/32blit-editor.exe`** directly. No compiler, SDK checkout, Python, or MSYS2 is needed for this tutorial.
2. Choose **File → New Project…**. Enter `My Pong`, leave **Pong tutorial (art and runner only)** checked, and click **Create…**. In Explorer, select the **parent folder** where you want `My Pong` to be created.
3. Follow [the Pong tutorial](docs/Pong.md) to create your clips, actors, and court. The new project starts with the PNGs and a game runner, but **no entities, sprite clips, or court**. Don't click **Play** until you've saved those assets.

**Completed example:** To compare, save your work, stop the game, and choose **File → Open Project… → Pong Reference**. It is separate from the project you create. Use **Open Project…** again to return to `My Pong`.

Dev and C++ builds are optional. See [source build setup](docs/SourceBuild.md) only if you want to change and compile the game's C++ code.
